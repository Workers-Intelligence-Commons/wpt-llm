# Output notice and attribution (draft clauses)

Draft, written without legal review. The license section numbers below are
to be checked against the official text, and the final wording must be seen
by a lawyer before publication.

## Principle

- The license text (AGPL-3.0-or-later) stays **intact**. The clauses below go
  in a file next to it (NOTICE, OUTPUT-NOTICE or the model card) that refers
  to the license.
- GPL and AGPL forbid adding further restrictions on recipients. Each clause
  must therefore stay a **permission, a recommendation or a statement of
  fact**, never a condition.
- A mandatory "ethical use" clause (RAIL licenses) would make the model
  incompatible: do not write one.

## What there is to say about outputs

- GPL and AGPL say (section 2, to check) that the output of a covered work is
  covered only if it is itself a derivative work. A model generating new text
  does not automatically pass its license on to its outputs, but for a model
  the line with a copy of what it learned is blurry: a clear sentence helps.
- One can only transfer rights one has. In many countries, generated text
  without real human creation is not protected by copyright: there is no
  ownership to give. What can be written is that **the model's authors claim
  no rights** over the outputs, and that whoever prompts the model does what
  they want with them.
- Liability: the licenses already disclaim warranty and limit liability
  (sections 15 and 16, to check). This can be repeated for outputs.
- The gap no clause fills: a model can reproduce pieces of its training data.
  If the piece comes from a source that requires attribution, whoever
  publishes the output without knowing it may breach that obligation toward
  the author. A contract can move responsibility, not remove it.

## Clause 1: output notice (permission)

```
Output notice (additional clarification, not a restriction)

The authors claim no copyright over text generated by running this model.
Whoever prompts the model is free to use, license, or publish the output
however they choose, and is solely responsible for how they use it,
including checking that it does not reproduce third-party material.
This notice grants permissions only and does not add any condition to the
GNU Affero General Public License, version 3 or later.
```

## Clause 2: attribution recommendation (non-binding)

```
Attribution recommendation (non-binding)

This model was trained on third-party material listed in its build record,
under licenses that may require attribution. Output from this model may
occasionally reproduce such material.

We recommend, but do not require, that when you publish output generated
with this model you mention it and link to <URL>, where the full list of
sources, authors and licenses is maintained. This is a courtesy to help
you and others meet attribution obligations. It does not change the terms
of the GNU Affero General Public License, version 3 or later, and does not
replace your own obligations toward the authors of any third-party
material you republish.
```

- Write "to help" and not "to comply": the link does not guarantee
  compliance. Attribution obligations arise when a piece of a source is
  actually reproduced, and fall on whoever republishes it.
- Some licenses accept attribution through a link to a page holding the
  information (CC BY 4.0 seems to, to check); others may not. Never write
  that the mention makes anyone compliant.

## Clause 3: transparency (statement of fact)

```
Transparency

This model was trained only on the sources listed in its build record, each
with its license and an exact pointer to the original. The full list, the
patches applied to it, and the build scripts are at <URL>. Anyone can check
what the model was trained on, and re-fetch each source by its checksum.
```

This clause recommends nothing and requires nothing: it describes reality,
so it carries no license risk. It also serves people who have no intention
of republishing but want to know what is in the model.

## Where to show it

Almost nobody reads a license file: the information must appear where people
look.

- **Model card** (the model's README): at the top, not the bottom.
- **Weight file metadata**: safetensors has a free metadata field in its
  header, GGUF has key-value pairs (license, URL); to check in each format's
  documentation. The link then travels with the weights.
- **The tool serving the model**: an `--about` command or an `/about` page
  showing the notice.
- **The repository README** and a NOTICE file.

## One source of truth

The source descriptions generate the NOTICE file, the public web page
(authors, licenses, links), the model card block and the metadata text, so
the four cannot contradict each other, and CI checks they are up to date.

- **A stable URL**: this link will be copied everywhere and can never be
  corrected in outputs already published. A controlled domain name is better
  than a link to a GitHub branch.
- A page readable by humans, not only a JSON file.
